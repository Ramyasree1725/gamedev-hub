About GameDev Hub

A simple yet complete full-stack project for learning game development.

Project Goals

  • Demonstrate working frontend + backend integration
  • Provide multiple fully playable mini-games
  • Show how to submit and display scores via REST API
  • Teach core game programming concepts through real code
  • All buttons, navigation and game controls are functional

Tech Stack

  • Backend: Python Flask, CORS, in-memory leaderboard
  • Frontend: HTML5, CSS3, Vanilla JavaScript
  • Graphics: HTML5 Canvas API
  • Fonts: Orbitron + Inter (Google Fonts)

How to Run Locally

cd backend
pip install -r requirements.txt
python app.py
# Open http://localhost:5000

Features Checklist
